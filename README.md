# CryptoX

A production-style Android cryptocurrency portfolio and market tracking application built with Kotlin, Jetpack Compose, Clean Architecture, MVVM, Hilt, Room, Firebase, and REST APIs.

## Features

📈 **Market Tracking** — View live cryptocurrency prices, market data, and price changes.

⭐ **Favorites / Watchlist** — Add and manage cryptocurrencies in a personalized watchlist.

💼 **Portfolio Management** — Track holdings, quantities, average buy prices, current values, and portfolio performance.

💱 **Currency Conversion** — Switch the application's display currency and view portfolio/market values in the selected currency.

📱 **Home Screen Widget** — Glance-based portfolio widget for quickly viewing holdings without opening the app.

🔐 **Authentication** — Firebase Authentication with secure user-specific data.

☁️ **Cloud Data** — Firebase Firestore for synchronizing favorites and portfolio information.

🔄 **Reactive Data Flow** — Kotlin Coroutines and Flow/StateFlow for asynchronous and observable data handling.

🧭 **Deep Linking** — Navigate directly to relevant screens and assets from supported links.

## Architecture & Technologies

**Kotlin · Jetpack Compose · MVVM · Clean Architecture · Hilt · Coroutines · Flow · Room · Firebase Authentication · Firestore · Glance · Retrofit · REST APIs**
